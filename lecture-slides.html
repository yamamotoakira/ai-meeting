3-2

APIキーの取得手順

Anthropic（Claude用）

  • console.anthropic.com にアクセス
  • アカウント作成 / ログイン
  • 「API Keys」メニュー
  • 「Create Key」をクリック
  • 名前をつけて作成
  • この瞬間にコピー！

OpenAI（Codex用）

  • platform.openai.com にアクセス
  • アカウント作成 / ログイン
  • 「API Keys」メニュー
  • 「Create new secret key」
  • 名前をつけて作成（sk-...）
  • この瞬間にコピー！
⚠ APIキーは表示された瞬間にコピーしてください。ページを閉じると二度と見られません。
3-3

APIキーの安全な扱い方

APIキーを使うと使った分だけ課金される ── クレジットカード番号と同じくらい大事

絶対にやってはいけない3つのこと

NG行為なぜダメか
SNSに投稿するボットが即座に拾って不正利用される
他人に教えるその人の利用分も自分に請求が来る
メールやチャットで送る途中で盗まれる可能性がある

安全な管理方法

  • パスワードマネージャー（1Password、Bitwarden等）に保存
  • 利用上限（Spending Limit）を設定 ── 月$5〜10で安心
  • 漏洩したら → 即座にキーを無効化（Revoke）して再生成
Part 4

外部サービスとの連携

25分
4-1

Googleカレンダー連携

連携の設定をすれば、AIが直接カレンダーを見に行けるようになります

「来週の月曜から金曜で、2時間以上空いている時間帯を探して」
→ カレンダーを確認して空き時間を一覧表示
「水曜の14時から『AIチーム勉強会』という予定を入れて」
→ カレンダーにイベントを自動作成
予定の確認も追加も、AIに話しかけるだけ
4-2

Googleスプレッドシート連携

Google Drive 経由でスプレッドシートの中身を読み書きできます

「この家計簿スプレッドシートを読み込んで、月ごとの食費の推移をまとめて」
→ スプレッドシートのデータを読み取り、分析結果を返す
「アンケートの回答データを集計して、質問ごとの満足度の平均を出して」
→ データを読み込み、集計・分析
4-3

Gmail連携

「未読メールを内容ごとに分類して、急ぎ・確認・後で読むにラベルを付けて」
→ 内容に応じて自動でラベル付け・振り分け
「今日届いた未読メールを要約して」
→ 未読メールの要点を短く説明
「この内容で返信の下書きを作って：打ち合わせは来週火曜14時でOK」
→ 丁寧なビジネスメールの下書きを生成

※ 機密性の高い内容（契約書、個人情報など）には注意してください

4-5

Obsidian連携 ── 知識の整理棚

自分のPC上で動くノートアプリ。データが全て自分のパソコンに保存されるので安心

① Claude Codeで原案・アイデアを作る ↓ ② Obsidianに保存して整理する（タグ付け、リンク） ↓ ③ 次にClaude Codeを使うとき、Obsidianのノートを読み込ませる ↓ ④ 過去の知識を踏まえた、より良い成果物ができる ↓ ⑤ また保存する → ①に戻る
このサイクルで「AIとの作業履歴」が自分だけの知識ベースになる
4-6

連携の仕組み ── MCP（通訳さん）

MCP（Model Context Protocol）＝ AIと外部サービスをつなぐ通訳さん
あなた → Claude Code → MCPコネクタ → Googleカレンダー 「来週の空きを （通訳さん） （予定データ） 探して」 あなた ← Claude Code ← MCPコネクタ ← Googleカレンダー 「火曜の午後と （翻訳して （データを返す） 木曜の午前が わかりやすく） 空いています」

資料化の比較
Claude Code/Codex vs NotebookLM

10分
5-2 / 5-3

同じ内容を渡すと、どう違う？

Claude Code / Codex

  • AIの知識も加えて内容を膨らませる
  • HTML / Markdown / PDF など出力形式を自由に指定
  • 原案作成から資料化まで一気通貫
  • デザインはシンプル

NotebookLM

  • 渡した素材の中身だけを使う（正確）
  • 複数の資料を横断して分析
  • Audio Overviewで音声化
  • Googleアカウントだけで使える
